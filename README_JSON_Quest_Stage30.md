# JSON Quest — Stage 1〜30

ブラウザで動作するJSON学習ゲームです。ステージ1〜20を保持し、より高度なステージ21〜30を追加しました。

## 使い方

1. `index.html` をブラウザで開くか、GitHub Pagesで公開します。
2. 上部の番号ボタンでステージを選び、JSONを編集します。
3. 「実行・判定」で正誤を確認します。ヒント・初期化も利用できます。
4. 進捗と入力途中の内容は同じブラウザのローカルストレージに保存されます。

## GitHub Pagesへの公開

ZIPを展開した中の `index.html` をリポジトリのルートに置いてコミット・プッシュします。GitHubの **Settings → Pages** で **Deploy from a branch → main → /(root)** を選ぶと公開できます。

注意: JSON QuestはJSONデータの構造を練習する教材です。JavaScriptのコードを自由に実行する機能ではありません。
